# без аудио/TTS/датасет-генерации из requirements.txt (нужны только инференс-пайплайну
# M2, судья их не импортирует -- см. grep по import в src/judge*.py/run_eval.py/metrics.py).

# ВСЁ версионировано намертво (никаких голых имён/>=) -- это финальный пин по факту
# рабочей связки в DataSphere от 27.07, после нескольких неудачных попыток (полный разбор
# в docs/decisions.md, если понадобится восстановить контекст):
#   - системный preinstalled torch (2.0.1+cu118, живёт в ~/.local -- на этом non-root
#     пользователе нет отдельной "системной" копии для отката) несовместим с transformers,
#     который требует torch>=2.4;
#   - GPU-драйвер DataSphere поддерживает CUDA только до 12.2 (см. `nvidia-smi`) -- значит
#     годится torch под cu121, НЕ под latest/cu130 с обычного PyPI (тот качает секунды,
#     но `torch.cuda.is_available()` вернёт False -- драйвер слишком старый для рантайма);
#   - torchaudio/torchvision/torchtext/torchdata/fastai (preinstalled, не наши зависимости)
#     после апгрейда torch начинают ругаться в pip -- ожидаемо и безвредно: torchaudio
#     заменяется заглушкой в scripts/judge_setup.ipynb (transformers иначе тянет его
#     транзитивно и безусловно через loss/loss_rnnt.py -> ParakeetForRNNTLoss, для ASR-
#     модели, которую мы не используем), остальные три вообще не импортируются судьёй.
